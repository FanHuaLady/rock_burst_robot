| --------- | ------ | -------------- | ----------------------- |
| RMII 参考时钟 | PA1    | `RMII_REF_CLK` | LAN8720A `nINT/REFCLKO` |
| MDIO      | PA2    | `ETH_MDIO`     | LAN8720A 管理接口           |
| MDC       | PC1    | `ETH_MDC`      | LAN8720A 管理接口           |
| CRS_DV    | PA7    | `RMII_CRS_DV`  | RMII 接收控制               |
| RXD0      | PC4    | `RMII_RXD0`    | RMII 接收数据 0             |
| RXD1      | PC5    | `RMII_RXD1`    | RMII 接收数据 1             |
| TX_EN     | PB11   | `RMII_TX_EN`   | RMII 发送使能               |
| TXD0      | PB12   | `RMII_TXD0`    | RMII 发送数据 0             |
| TXD1      | PB13   | `RMII_TXD1`    | RMII 发送数据 1             |
| PHY 复位    | PC0    | `ETH_RESET`    | LAN8720A `nRST`         |
