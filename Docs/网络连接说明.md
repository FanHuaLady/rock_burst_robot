# 网络连接说明

机器人固件使用静态 IPv4 地址和 TCP 长连接，PC 与 Android 配置的板端地址一致：

```text
开发板地址: 192.168.1.50
子网掩码:   255.255.255.0
TCP 端口:   9090
```

以下构建和烧录命令均从 `Code` 目录执行。

## 电脑网线直连

电脑有线网卡设置为 `192.168.1.10/24`，然后构建 PC 配置：

```powershell
.\scripts\build.ps1 -Mode robot-pc
.\scripts\flash.ps1 -Mode robot-pc
```

先用 `ping 192.168.1.50` 验证链路，再让上位机连接 `192.168.1.50:9090`。

## Android 直连网络

手机和开发板需处于 `192.168.1.0/24` 网段，然后构建 Android 网络配置：

```powershell
.\scripts\build.ps1 -Mode robot-android
.\scripts\flash.ps1 -Mode robot-android
```

上位机须按 NDJSON 协议完成 `hello_ack` 握手，并在连接期间每 250-500 ms
发送 `ping`。完整消息格式见 [Android长连接协议.md](Android长连接协议.md)。

## 断线安全行为

TCP 连接关闭或错误、以太网链路断开，或连续 1000 ms 未收到有效协议消息时，
固件关闭全部机器人输出并进入 `safe`。上位机仍应提供明确的急停操作。
